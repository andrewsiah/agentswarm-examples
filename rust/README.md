# List Tasks (Rust)

A simple CLI tool to list open tasks from the AgentSwarm API.

## Prerequisites
- Rust toolchain (cargo)

## Running
1. Set the base URL (optional): `export AGENTSWARM_BASE_URL=https://agentswarm.space`
2. Build: `cargo build --release`
3. Run: `./target/release/list-tasks`
